WHAT IS SYCL SNAKE?

THE GAME

  • 100% Zig — no C runtime

THE TWIST

  • SIMD collision detection

WHY ZIG + SYCL?

ZIG GIVES US

  • No hidden control flow
  • Comptime metaprogramming
  • First-class @Vector types
  • Zero-cost error handling
  • Single binary, no libc dep

SYCL GIVES US

  • Portable GPU abstraction
  • Single-source heterogeneous code
  • OpenCL runtime compatibility
  • Offload bulk grid computations
  • CPU fallback when no GPU

// PCM sine-wave synthesis fn genTone( buf: []f32, freq: f32, sample_rate: u32, ) void { const step = freq / @as(f32, @floatFromInt(sample_rate)); var phase: f32 = 0; for (buf) |*s| { s.* = @sin(phase * std.math.tau); phase += step; if (phase > 1) phase -= 1; } }

SIMD COLLISION DETECTION

THE PROBLEM

  • Grid = 40 × 20 = 800 cells
  • Naïve O(n) body-position walk
  • Did head collide with any body?

THE SOLUTION

  • Pack coords into @Vector(8,u8)
  • SIMD compare vs. head pos
  • @reduce(.Or, …) → boolean
  • ~100× fewer instructions
// SIMD body-collision check const V = @Vector(8, u8); var hit = false; var i: usize = 0; while (i + 8 <= body.len) : (i += 8) { const chunk: V = body[i..][0..8].*; const splat: V = @splat(head_idx); const mask = chunk == splat; hit = hit or @reduce(.Or, mask); } if (hit) state.die();

CHALLENGES

WHAT WENT WRONG

  • Terminal raw mode
    Platform TTY setup differences
  • Audio latency
    Buffer size vs. latency tradeoff
  • SYCL toolchain
    Linker flags differ per runtime
  • Windows ANSI
    VT100 not default in cmd.exe

HOW WE FIXED IT

  • comptime OS dispatch
    Per-platform TTY init at comptime
  • Tunable ring buffer
    -Dlatency=low build flag
  • build.zig auto-detect
    Walks PATH for sycl-ls runtime
  • SetConsoleMode()
    ENABLE_VIRTUAL_TERMINAL on start
